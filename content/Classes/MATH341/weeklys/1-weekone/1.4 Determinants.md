All properties of determinants remain th same for matrices over $\mathbb{R}$ and $\mathbb{C}$. Here are some notable ones
## Theorem 1.15 Properties of determinants

1. If $B$ is obtained from $A$ through row swaps, then $\det B = \det A$

2. If $B$ is obtained from $A$ through multiplying a row by a scalar $c$, then $\det B = c \det A$

3. $\det A^T = \det A$

4. $\det(AB) = \det(A) \det(B)$

5. $A$ is invertible $\iff$ $\det A \neq 0$.

6. $\det A$ can be obtained using co-factor expansion along any row/column
