# 1.4 Vector spaces
A nonempty set $V$ (consisting of elements called vectors) is called a vector space over $\mathbb{F}$ (where $\mathbb{F} = \mathbb{R} \text{ or } \mathbb{C}$), if there is a binary operation + and a scalar multiplication $\times$ that satisfy the following properties

1. **Closure**:
- For every two vectors $\vec{a} , \vec{b} \in \mathbb{R}^n$ , and every scalar $c \in \mathbb{R}$, both $\vec{a} + \vec{b}$ and $c\vec{a}$ are within $\mathbb{R}^n$

2. **Associativity**:
- For every $\vec{a} , \vec{b} , \vec{c} \in \mathbb{R}^n$. Then $\vec{a} + (\vec{b} + \vec{c}) = (\vec{a} + \vec{b}) + \vec{c}$. 
- Also consider the past vectors; for every $x,y \in R$, then $x(y\vec{a}) = (xy)\vec{a}$

3. **Commutativity**
- For every $\vec{a},\vec{b} \in \mathbb{R}^n$, we have $\vec{a} + \vec{b} = \vec{b} + \vec{a}$

4. **Additive identity**
- For every $\vec{a} \in \mathbb{R}^n$ we have $\vec{a} + (0,0,...0_n) = \vec{a}$. 
- i.e. if we add a vector with all components 0 to $\vec{a}$ then nothing happens

5. **Additive inverse**
- For every $\vec{a} \in \mathbb{R}^n$, there is a vector $\vec{b} \in \mathbb{R}^n$ for which $\vec{a} + \vec{b} = 0$
- This vector $\vec{b}$ is called the additive inverse of $\vec{a}$ and is denoted as $-\vec{a}$. ($-1\vec{a}$)

6. **Distributivity**
- For every $x,y \in \mathbb{R}$ and $\vec{a},\vec{b} \in \mathbb{R}^n$, we have $(x+y)\vec{a} = x\vec{a} + y\vec{a}$ and $x(\vec{x} + \vec{y} = x\vec{a} + x\vec{b})$ 

7. **Multiplicative Identity**
- For every $\vec{a} \in \mathbb{R}^n$ we have $1\vec{a} = \vec{a}$ 

When $\mathbb{F} = \mathbb{R}$, we say the vector space $V$ is a real vector space, and when $\mathbb{F} = \mathbb{C}$, we say the vector space $V$ is a complex vector space
### Note about notation

- Similarly, $C^{n}(\mathbb{R})$ is the set of all functions $\mathbb{R} \rightarrow \mathbb{R}$ with continuous $n$th derivatives

- $C^{\infty}(\mathbb{R})$ are all functions $\mathbb{R} \rightarrow \mathbb{R}$ that are $\mathbb{C}^\infty$ [[7.4 Curves in Rn (derivatives)#7.7 Continuous differentiability|see definition]]

## 1.5 Subspaces
 A subset $W$ of a vector space $V$ is called a subspace if $W$ along with the same operations of $V$ is itself a vector space
## Theorem 1.6 [[2.1 Subspaces#Theorem 2.1 Criteria for a subspace|Subspace criterion]]
A subset $W$ of $\mathbb{R}^n$ is a subspace if and only if it satisfies all of the following:

- $W$ contains the zero vector

- for all $\vec{x},\vec{y} \in W \text{ and } c \in \mathbb{R}$, we have $\vec{x} + \vec{y} \in W \text{ and } c\vec{x} \in W$. (We say $W$ is closed under vector addition and scalar multiplication)

So for instance, $\mathbb{R}^n$ is a real subspace of $\mathbb{C}^n$ 
## 1.6 Linear combinations
Let $S = {{\bf v}_1, . . . , {\bf v}_n}$ be a subset of a vector space $V$ , and w be a vector in $V$ . We say ${\bf w}$ is a linear combination of $S$ (or elements of S) if 
$$
w = c_1{\bf v}_1 + \cdots + c_n{\bf v}_n \text{ for some } c_1, \cdots , c_n \in \mathbb{F}
$$
By definition, the only linear combination of the empty set is ${\bf 0}$ , the zero vector
## [[2.2 Linear dependency, spanning, and basis#2.3 Linear dependency|1.7 Linear dependency]]
We say vectors $\vec{v}_1,\vec{v}_2,...,\vec{v}_m \in \mathbb{F}^n$ are linearly dependent if **one** or more of these vectors can be written as a linear combination of the others. Otherwise, we say $\vec{v}_1,\vec{v}_2,...,\vec{v}_m$ are linearly independent.
## [[2.2 Linear dependency, spanning, and basis#Theorem 2.2|Theorem 1.7]]
The vectors $\vec{v}_1,...\vec{v}_m \in \mathbb{F}^n$ are linearly dependent if and only if there are numbers $c_1,...,c_m \in \mathbb{F}$ (they can't all be zero) such that $c_1 \vec{v}_1 + c_2 \vec{v}_2 + ... + c_m\vec{v}_m=\vec{0}$. 

In other words., vectors $\vec{v}_1,\vec{v}_2,...,\vec{v}_m$ are independent if and only if the following is also true:
$$
\text{If } c_1\vec{v}_1+c_2\vec{v}_2+...+c_m\vec{v}_m=\vec{0} \text{ for some scalars } c_1,c_2,...,c_m \text{ then } c_1=c_2=...=c_m=0
$$
## [[2.2 Linear dependency, spanning, and basis#2.4 Spanning|1.8 Spanning]]
Given a subspace $V$ of $\mathbb{R}^n$. we say a set $S \subseteq V$ is **spanning** if every $\vec{v} \in V$ can be defined as a linear combination $\exists \vec{a} \in S$. i.e. $S$ spans $V$ if we can write all of the vectors in $V$ using linear combinations of the at least some vectors in $S$
## [[2.2 Linear dependency, spanning, and basis#2.5 Basis|1.9 Basis]]
We say a subset $B$ of a subspace $V \in \mathbb{R}^n$ if a **basis** if $B$ is both linearly independent and spanning.
- $B \subseteq V$ is linearly independent
- $B$ is [spanning](2.2%20Linear%20dependency,%20spanning,%20and%20basis.md#2.4%20Spanning) 
## Theorem 1.8
Suppose $V$ is a vector space with a basis consisting of $n$ vectors

1. If $m$ is an integer greater than $n$, then every $m$ vectors of $V$ are linearly dependent

2. Every basis of $V$ has exactly $n$ vectors

3. Every $n$ linearly independent vectors in $V$ form a basis for $V$ 

4. Every $n$ spanning vectors in $V$ form a basis for $V$

### Note about determining whether a vector space is real or complex

In order to determine define a vector space we need to define both vector addition and scalar multiplication. If the scalar of our choice MUST be real, then the vector space is real. Instead, if our scalar can be complex, then the vector space is complex.

For instance, the vector space $M_{n}(\mathbb{R})$ is only real (if we use regular matrix scalar multiplication) because if we multiply a square matrix with real entries by a complex number then it could be that the matrix's entries would become complex. 

**Note that every complex vector space can be either real or complex**
