## 1.1 Complex numbers $\mathbb{C}$
The set of complex numbers $\mathbb{C}$ is defined as 
$$
\mathbb{C} = \{a + bi \,|\, a,b \in \mathbb{R} \}
$$
Where $i^2 = -1$. The form $a + bi$ for a complex number is called its standard form. Two complex numbers $a + bi$ and $c + di$ with $a, b, c, d \in \mathbb{R}$ are said to be equal if and only if $a = c$ and $b = d$. We say $a$ and $b$ are the real and the imaginary parts of the complex number $z = a + bi$, respectively. We denote these by $\Re(z)$ and $\Im(z)$, respectively

i.e. $a + bi$ where $a$ is the real part and $b$ is the imaginary part. Two complex numbers are equal iff both their real and imaginary parts are equivalent

![[geometrycomplex.png]]

This notations is sort of like $\hat{i}, \hat{j}$ with vectors. 

Complex numbers are defined with two main operations, (complex) addition and (complex) multiplication as follows

- $(a + bi) + (c + di) = (a + c) + (b + d)i$

- $(a + bi)(c + di) = ac + adi + bci - bd = (ac - bd) + (ad + bc)i$ 
	i.e. just foil the two numbers . Remember $i^2 = -1$

for $a, b, c, d \in \mathbb{R}$
# 1.2 Complex conjugates
For a complex number $z = a + bi$ its complex conjugate $\bar{z}$ is defined as 
$$
\bar{z} = a - bi
$$
i.e. its reflection on the real numbers line. its absolute value is defined  absolute value (or norm) as 
$$
|z| = \sqrt{a^2 + b^2}
$$
## Theorem 1.1 Properties of complex numbers
For every $x, y, z \in \mathbb{C}$ we have

- $x + y = y + x$ 
	Commutativity

- $(x + y)z = xy + yz = x + (y + z)$ 
	Associativity

- $x + 0 = x$ where $0 = 0 + 0i$ 
	Additive identity

- There is a $t \in \mathbb{C}$ for which $x + t = (0 + 0i)$ (just negate $x$'s components)
	Additive inverse

- If $x \neq 0$ there is some $t \in \mathbb{C}$ for which $xt = (1 + 0i)$
	Multiplicative inverse

- $x(y + z) = xy + xz$
	Distributivity

## Theorem 1.2 Properties of conjugates & norms
For $z, w \in \mathbb{C}$ we have

- $\overline{zw} = \bar{z} \bar{w}$

- $|zw| = |z| |w|$ 

- $|z|^2 = z \bar{z}$

- $|z + w| \leq |z| + |w|$

## Example 1.1
Find the additive and multiplicative inverses of $3 + 2i$
### Additive inverse
We want a number $a + bi \in \mathbb{C}$ such that $(3 + 2i) + (a+ bi) = 0 + 0i$. i.e. $a$ and $b$ such that
$$
\begin{cases}
	3 + a = 0 \\
	2 + b = 0
\end{cases}
$$
So $a = -3$ and $b = -2$.
### Multiplicative inverse
We want a number $a + bi \in \mathbb{C}$ such that $(3 + 2i)(a + bi) = (1 + 0i)$. Working this out, 
$$
(3 + 2i)(a + bi) = 3a + 3bi + 2ai - 2b = (3 - 2b) + (2a + 3b)i = 1 + 0i
$$
Yielding the systems 
$$
\begin{cases}
	3a - 2b = 1 \\
	2a + 3b = 0
\end{cases}
$$
From the second we can deduce $a = -\frac{3}{2}b$ And thus
$$
\begin{flalign}
	1 & = 3\left(-\frac{3}{2}b\right) - 2b \\
	-1 & = \frac{9}{2}b + 2b \\
	& -1 = \frac{13}{2}b \\
	\Rightarrow  b &= -\frac{2}{13}
\end{flalign}
$$
And thus $a = -\frac{3}{2}-\frac{2}{13} = \frac{3}{13}$. So $a = \frac{3}{13}$ and $b = -\frac{2}{13}$

## 1.3 The geometry of the complex plane
Each complex number $z = a + bi$ can be plotted on a plane called the complex plane. The horizontal axis consists of all real numbers and the vertical axis consists of all complex numbers with zero real part. If $\theta$ is the angle between $0z$ and the positive real axis, then 
$$
z = |z|(\cos \theta + \sin\theta i)
$$
## Theorem 1.3 [Euler's formula](https://en.wikipedia.org/wiki/Euler%27s_formula)
For every $\theta \in \mathbb{R}$ we have
$$
e^{i\theta} = \cos \theta + \sin\theta i
$$
This is where Euler's identity $e^{\pi i} = -1$  comes from, btw
### A proof:
Consider how
$$
\cos \theta  = \sum_{n = 0}^{\infty}(-1)^n \frac{\theta^{2n}}{(2n)!} = 1 - \frac{\theta^2}{2!} + \frac{\theta^4}{4!} + \cdots
$$

And how 
$$
\sin \theta i = \sum_{n = 0}^{\infty}(-1)^n \frac{\theta^{2n + 1}}{(2n + 1)!} = \theta i - \frac{(\theta i)^3}{3!} + \frac{(\theta i)^5}{5!} + \cdots
$$
Note that $-\frac{(\theta i)^3}{3!} = i\frac{\theta^3}{3!}$  and $-\frac{(\theta i)^2}{2!} = \frac{\theta^2}{2!}$ since $i^2 = -1$ thus
$$
\cos\theta + i\sin\theta = 1 + \theta i  + \frac{(\theta i)^2}{2!} + \frac{(\theta i)^3}{3!} + \cdots = e^{i\theta}
$$

## Example 1.2 
Evaluate the following integral
$$
\int e^x \cos x \ dx
$$
From Euler's formula we have that
$$
\cos x = e^{ix} - \sin xi
$$
So the integrand be be re-written as
$$
\int e^x(e^{ix} - \sin x) \ dx = \int e^xe^{ix} - e^x\sin x i \ dx
$$
Here, we can ignore the imaginary right side [citation needed] and simply look at the real part (split the integral)
$$
\Re\left(\int e^xe^{ix} - e^x\sin x i \ dx\right) = \int e^xe^{ix} \ dx
$$
This can be turned into
$$
\Rightarrow \int e^{x + xi} \ dx = \int e^{x(1 + i)} \ dx = \frac{e^{x(1 + i)}}{1 + i} + C
$$
*Note that dividing by an imaginary number is the same thing as multiplying by the multiplicative inverse.*
Now, we can simplify the fraction by multiplying it by the complex conjugate $1 - i$ of the bottom number $1 + i$
$$
\Rightarrow \frac{e^{x(1 + i)}}{(1 + i)(1 - i)} + C = \frac{e^{x(1 + i)}(1 - i)}{1 - i + i - 1} + C= \frac{e^{x(1 + i)}(1 - i)}{2} + C
$$
Recall that $e^{x(1 + i)} = e^xe^{xi} = e^x(\cos x + \sin x i)$ 
$$
\Rightarrow \frac{e^x (\cos x + \sin xi) (1 - i)}{2} + C = \frac{e^x(\cos x + \sin x + \sin xi - \cos xi)}{2} + C
$$
$$
\Rightarrow \frac{e^x(\cos x + \sin x)}{2} - \frac{e^x(\sin x - \cos x)}{2}i
$$
The real part of this is $\frac{e^x(\cos x + \sin x)}{2}$ which is then the answer $\square$

## 1.4 Complex exponentiation

$$
e^z = e^a(\cos b + i\sin b)
$$
