# 1.12 Linear transformations
 Let $V, W$ be two vector spaces over $\mathbb{F}$. A function $L : V → W$ is said to be linear (or a linear transformation) if for all ${\bf v}, {\bf w} \in \mathbb{F}$ and $c \in \mathbb{F}$

1. $L({\bf v} + {\bf w}) = L({\bf v}) + L({\bf w})$ 
	Additivity

2. $L(c{\bf v}) = cL({\bf v})$ 
	Homogeneity

## Theorem 1.9
 Let $L : V → W$ be a function between vector spaces over $\mathbb{F}$. Then, the following are equivalent

1. $L$ is linear

2. $L({\bf u} + c{\bf v}) = L({\bf u}) + cL({\bf v})$ for all $\vec{u}, \vec{v} \in V$ and all $c \in \mathbb{R}$

3. $L(a{\bf u} + b{\bf v}) = aL({\bf u}) + bL({\bf v})$ for all ${\bf u}, {\bf v} \in V$ and all $c \in \mathbb{F}$

# Theorem 1.10
Let $A$ be an $m \times n$ matrix. Suppose $E$ is an echelon form of $A$ obtained by row reducing $A$. Suppose $E$ has $r$ pivot columns. Then,

1. The dimension of the column space and row spaces of $A$ are $r$

2. The dimension of the kernel of $A$ is given by $n - r$

3. $\text{dim Ker } A + \text{dim Ker Col}  A = n$

## 1.13 Invertible matrices
A square matrix $A$ is called invertible if there exists some square matrix $B$ such that $AB = I$

1. The rank of a matrix is the dimension of its column/row space

2. The trace of a square matrix $A$ is the sum of its main diagonal entries and is denoted by $\text{tr } A$ or trace $A$ 
## Theorem 1.11
For a matrix $A \in M_n(\mathbb{F})$ the following are equivalent

1. $A$ is invertible

2. $\text{Col } A = \mathbb{F}^n$

3. $\text{Ker } A = \{{\bf 0}\}$ 

### Finding the inverse of a square matrix
To find the inverse of a square matrix A we form the augmented matrix $(A|I)$. Apply row operations until we obtain the matrix $(I|B)$. This matrix $B$ is the inverse of $A$

## 1.14 Matrix multiplication
Let $A$ be an $m \times n$ and $B$ be an $n \times k$ matrix. The matrix $AB$ is an $m \times k$ matrix whose $j$-th column is obtained from multiplying $A$ by the $j$-th column of $B$. In other words, the $(i, j)$ entry of $AB$ is obtained by finding the dot product of the $i$-th row of $A$ with the $j$-th column of $B$. 

Remark. For every $m \times n$ matrix $A$ and every column vector ${\bf v} \in \mathbb{R}^n$ the vector $A{\bf v}$ is a linear combination of columns of $A$ with coefficients from entries of ${\bf v}$.
## Theorem 1.12
A function $T : \mathbb{F}^n \rightarrow \mathbb{F}^m$ is linear if and only if there is an $m \times n$ matrix $A$ for which $T ({\bf v}) = A{\bf v}$ where every column vector ${\bf v} \in \mathbb{F}^n$. Furthermore, for a given linear mapping $T$ the matrix $A$ is unique, and the columns of $A$ are given by
$$
T({\bf e}_1), T({\bf e}_2), \dots, T({\bf e}_n)
$$
## Theorem 1.13
Let $A$ and $B$ be two square matrices, then

1. $(AB)^T = B^TA^T$

2. If $A$ and $B$ are invertible, then $AB$ is also invertible and $(AB)^{-1} = B^{-1}A^{-1}$

3. If $A$ is invertible, then $A^T$ is also invertible and $(A^T)^{-1} = (A^{-1})^T$

## Theorem 1.14
Let $T : V \rightarrow W$ be a linear transformation between vector spaces and let ${\bf w} \in W$. Then, either the inverse image $T^{-1}({\bf w})$ is either empty or is equal to
$$
T^{-1}({\bf w}) = {\bf v} + \text{Ker } T = \{{\bf v} + {\bf u} \,|\, {\bf u} \in \text{Ker } T\}
$$
for all ${\bf v} \in T^{-1}(\{\bf w\})$ 

i.e. the pre-images of a linear function are translations of its kernel space
### Pf.
Suppose ${\bf x}, {\bf v} \in T^{-1}(\{\bf w\})$ where ${\bf x} = {\bf v} + {\bf u}$ where ${\bf u} \in V$. We have that ${\bf u} = {\bf x} - {\bf v}$. Consider
$$
T({\bf u}) = T({\bf x} - {\bf v}) \Rightarrow \text{Linearity} \Rightarrow T({\bf x}) - T({\bf v}) = {\bf w} - {\bf w} = 0
$$
And thus ${\bf u} \in \ker T$.

Suppose ${\bf v} \in T^{-1}(\{\bf w\})$ and ${\bf u} \in \ker T$. Let ${\bf x} = {\bf v} + {\bf u}$. Consider
$$
T({\bf x}) = T({\bf v} + {\bf u}) \Rightarrow \text{Linearity} \Rightarrow T({\bf v}) + T({\bf u}) = {\bf w} + {\bf 0} = {\bf w}
$$
And thus ${\bf x} \in T^{-1}(\{{\bf w}\})$
