## 12.8 Vector fields
A vector field is some function ${\bf F} : D \rightarrow \mathbb{R}^n$ where $D \subseteq \mathbb{R}^n$. Essentially just some $n \times n$ function
## 12.9 Vector line integrals
Let $D \subseteq \mathbb{R}^n$ that contains the image of a path given by ${\bf x} : [a,b] \rightarrow \ \mathbb{R}^n$. The vector line integral of a vector field $F: D \rightarrow \mathbb{R}^n$ over ${\bf x}$ is given by
$$
\int\limits_{{\bf x}} {\bf F} \cdot d{\bf s} = \int\limits_{a}^{b} {\bf F} \circ {\bf x}(t) \cdot {\bf x}'(t) \ dt
$$
Very similar to the definition in [[12.3 Scalar line integrals]].

## Example 12.10
Find the work done by a force ${\bf F}(x,y,z) = (x, y^3, 2z^3)$ along the curve ${\bf x}(t) = (t, t^2, t)$ from $(0,0,0) \rightarrow (1,1,1)$ 

First lets find ${\bf x}'(t)$ 
$$
{\bf x}'(t) = (1, 2t, 1)
$$
Then compose ${\bf F}$ with ${\bf x}$ 
$$
{\bf F} \circ {\bf x} (t) = (t, t^6, 2t^3)
$$
Take the dot product of these two
$$
{\bf F} \circ {\bf x} \cdot {\bf x}' = t + 2t^7 + 2t^3
$$
Then finally integrate with respect to $t$
$$
\int\limits_{0}^{1} t + 2t^7 + 2t^3 \ dt = \frac{1}{2}t^2 + \frac{1}{4}t^8 + \frac{1}{2}t^4 \Big|_{t=0}^{t=1} = \frac{5}{4}
$$
So the work done is $\frac{5}{4}$

## 12.10 Piecewise continuous differentiability
A function ${\bf x}:[a,b] \rightarrow \mathbb{R}^n$ is said to be piecewise continuously differentiable if ${\bf x}$ is continuous, and the interval $[a,b]$ can be partitioned into finitely many intervals $a = t_0 < \cdots < t_n = b$ for which ${\bf x}$ is continuously differentiable on each interval $(t_i, t_{i+1})$
## 12.11 Reparameterization orientation
Let $x : [a, b] → \mathbb{R}^n$ be a piecewise continuously differentiable path. We say another piecewise continuously differentiable path $y : [c, d] → \mathbb{R}^n$ is a reparameterization of $x$ if there is a bijective continuously differentiable function $u : [c, d] → [a, b]$ whose inverse is also continuously differentiable such that $y = x ◦ u.$ 

If $y(c) = x(a)$, and $y(d) = x(b)$, then we say $y$ is orientation-preserving. If $y(c) = x(b)$, and $y(d) = x(a)$, then we say y is orientation-reversing

Essentially when we reparametrize a curve, it could either preserve the original direction of the parametrization, or it could reverse it.

For instance, if we have a polar parametrization $r(t) = (\cos t, \sin t)$ for $t \in [0, 2\pi]$, we could reparametrize it using some function like 
$$
\varphi(s) =  s + \pi
$$
For $s \in [0, 2\pi]$ such that
$$
r \circ \varphi (s) = r(s + \pi) = (\cos(s + \pi), \sin(s + \pi)
$$
Which will preserve the original orientation of $r$. To reverse it we could do something like $2\pi - s$ instead
## Theorem 12.4
Suppose $f : U → \mathbb{R}$ is a continuous function over an open subset $U$ of $\mathbb{R}^n$. Suppose ${\bf x}$ is a path whose image is inside $U$. If ${\bf y}$ is a reparameterization of ${\bf x}$, then
$$
\int\limits_{{\bf y}} f \ ds = \int\limits_{{\bf x}} f \ ds
$$
## Theorem 12.5
Suppose ${\bf F} : U → \mathbb{R}^n$ is a continuous vector field over an open subset $U$ of $\mathbb{R}^n$. Suppose ${\bf x}$ is a piecewise continuously differentiable path whose image is inside $U$ . If ${\bf y}$ is an orientation-preserving reparameterization of ${\bf x}$, then
$$
\int\limits_{{\bf y}} {\bf F} \cdot \text{d}{\bf s} = \int\limits_{{\bf x}} {\bf F} \cdot \text{d}{\bf s}
$$
If ${\bf y}$ is orientation-reversing, then
$$
\int\limits_{{\bf y}} {\bf F} \cdot \text{d}{\bf s} = -\int\limits_{{\bf x}} {\bf F} \cdot \text{d}{\bf s}
$$
Basically the same thing as the one in [[12.3 Scalar line integrals]]. I.e. If ${\bf y}$ reverses the orientation of ${\bf x}$, then negate the vector line integral. 
## Theorem 12.6
Let $C$ be a curve given by a parametrization ${\bf x} : [a, b] → \mathbb{R}^n$. Suppose $c ∈ (a, b)$ and the restriction of ${\bf x}$ to intervals $[a, c]$ and $[c, b]$ divides $C$ into two curves $C_1$ and $C_2$. Then for every vector field ${\bf F}$ and every scalar function $f$ we have
$$
\int\limits_{C} {\bf F} \cdot \text{d}{\bf s} =  \int\limits_{C_1} {\bf F} \cdot \text{d}{\bf s} + \int\limits_{C_2} {\bf F} \cdot \text{d}{\bf s} 
\,\,\,\, \text{ and } \,\,\,\
\int\limits_{C} f \cdot \text{d}{\bf s} =  \int\limits_{C_1} f \ \text{ds} + \int\limits_{C_2}  f \ \text{ds}
$$
I.e. you can split up $C$ into different curves and add the resulting integrals

## Example 12.12
Let $C$ be the curve of the intersection of the cylinder $x^2 + y^2 = 1$ and the plane $x + y + z = 2$ oriented clockwise when viewed from above. Evaluate
$$
\int\limits_{C} {\bf F} \cdot ds
$$
Where $F(x,y,z) = (x+y, x^2, y-z)$. 

Firsts, $C$ looks like this

The projection of $C$ onto the $xy$ plane is a circle of radius $1$. Thus, we can use the follow parametrization
$$
x(t) = \cos t \,\,\,\,\,\, y(t) = \sin(t) \,\,\,\,\,\, z(t) = 2 - \cos t- \sin t
$$
for $t \in [0, 2\pi]$. ${\bf r}'(t)$ is then $(-\sin t, \cos t, \sin t - \cos t)$. From this,, we also deduce 
$$
F \circ {\bf r}(t) = (\cos t + \sin t, \cos^2 t, 2\sin t - 2 + \cos t)
$$
So the integral will be
$$
\int\limits_{a}^{b} {\bf F} \circ {\bf x}(t) \cdot {\bf r}'(t) \ dt 
=
\int\limits_{0}^{2\pi} (\cos t + \sin t, \cos^2 t, 2\sin t - 2 + \cos t) \cdot (-\sin t, \cos t, \sin t - \cos t) \ dt
$$
Computing the dot product 
$$
\int\limits_{0}^{2\pi} -\cos t \sin t + \cos^3 t + 2\sin^2 t - \cos^2t - 2\sin t + 2\cos t - \sin t \cos t \ dt
$$
This simplifies to 
$$
\int_{0}^{2\pi} \sin^2 t + \cos^2 t - \cos^2 t - 2\cos t \sin t + 2\cos t - 2\sin t \ dt
$$
This whole thing evaluates to $0$ (proof by online calculator).
